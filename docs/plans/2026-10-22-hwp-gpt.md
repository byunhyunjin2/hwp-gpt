# HWP_GPT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 한컴 한글 창 오른쪽에 붙는 ChatGPT 패널. 말로 요청하면 열린 문서를 COM으로 바로 고치고, 고친 곳을 표시하고, 사용자의 수정 습관을 물어본 뒤 기억한다. ChatGPT 유료 사용자가 추가 비용 없이 설치해서 쓴다.

**Architecture:** 프로세스 3개. ① 패널 앱(Python, pywebview UI, 도킹·기억·학습) ② 번들 Codex CLI(`codex exec`, ChatGPT 로그인, 전용 `CODEX_HOME`) ③ 도구 서버(stdio MCP, Python, COM 전용 스레드 1개). Codex는 도구 서버의 도구로만 문서를 만지고, 도구 서버 안의 규칙 엔진(`rules.py`)을 통과한 수정만 한글에 반영된다. 도구 서버는 이번 요청의 결과(바꾼 곳·확인 항목)를 세션 파일에 남기고 패널이 그걸 읽어 표시한다.

**Tech Stack:** Python(Task 1에서 버전 확정), pywin32, pywebview, mcp(FastMCP), Codex CLI(Apache-2.0, 번들), pytest, PyInstaller

**Spec:** `docs/design.md` (v2)

## Global Constraints

- Windows 10/11 + 한컴오피스, COM ProgID `HWPFrame.HwpObject` (2022 검증)
- AI는 **Codex CLI + ChatGPT 로그인만**. Codex 실행 환경에서 `OPENAI_API_KEY`·`CODEX_API_KEY` 제거
- `CODEX_HOME = %APPDATA%\HWP_GPT\codex` — 사용자의 `~/.codex` 읽기·쓰기 금지
- 기억 위치 `%APPDATA%\HWP_GPT\memory\<문서종류>.md`, 작업 폴더 `%APPDATA%\HWP_GPT\work`
- 문서 저장 코드 금지 (`Save`/`SaveAs`/`FileSave` 호출 없음)
- hwp-mcp 보안 모듈 DLL 등록 금지, 한글 확인창 우회 금지
- 기억 저장은 사용자가 카드에서 [저장]/[고쳐서 저장]을 눌렀을 때만
- 패널 기본 폭 380px, 색: 바꿈 노랑 / 안 바꿈·확인 빨강
- 실제 업무 문서 커밋 금지. 테스트 문서는 코드로 생성
- **매 커밋에 기록 갱신 포함** (AGENTS.md): 바뀐 것 → `CHANGELOG.md`, 확인된 사실 → `docs/NOTES.md`, 실수 → `docs/MISTAKES.md`
- 커밋 메시지 끝: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. **한글이 안 켜져 있거나 작업 중 닫힘** → 패널·도구 서버 모두 죽지 않음, "한글 문서를 열어 주세요", 다시 열면 재연결 (Task 3, Task 8)
2. **연도 숫자가 식별번호·금액 안에 있음** (`202699001`, `2,026,000`) → 치환 안 함 (Task 2)
3. **날짜 표기 제각각** (`2026. 10. 31.(토)`, `2026.10.31(토)`, `2026년 10월 31일(토)`) → 표기 유지, 요일만 재계산 (Task 2)
4. **로그인 안 됐거나 만료 / 사용 한도 도달** → 패널이 [ChatGPT로 로그인] 또는 "사용 한도 도달, 잠시 후 다시" 표시, 문서는 건드리지 않음 (Task 5, Task 8)
5. **표시가 남은 채 저장하려 함 / 표시 주변을 사용자가 손댐** → 경고 유지, [표시 모두 지우기]가 패널이 넣은 표시를 모두 제거 (Task 3, Task 8)
